The Hermes skill lives at the repository root:

`skills/hermes-companion/SKILL.md`

Install it with:

```bash
hermes skills install danielmain/hermes-companion/skills/hermes-companion
```

`user-location` and `user-health` are one skill now. Place, motion, sleep, workouts, and recovery share `scripts/companion.py`.

The skill text is English. The agent answers in the user's language and keeps saved place names as written. It does not report phone battery.
